# Apollo Validator Infrastructure

Automated audit for Apollo Celestia Validator.

## Live Status

See [VALIDATOR-AUDIT.md](VALIDATOR-AUDIT.md) — auto-updated every 6 hours.

## Setup (on server)

```bash
git clone https://github.com/Zelivsky/apollo-validator-infra.git
cd apollo-validator-infra
chmod +x setup-audit.sh
./setup-audit.sh
```
